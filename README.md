# Paradise Nursery Shopping Application

Paradise Nursery is an online plant shop web application built using React and Redux Toolkit. Users can browse various categories of houseplants, view details, add items to their shopping cart, manage item quantities, and review total costs.

## Features
- Dynamic landing page with background image and "Get Started" navigation.
- Category-based product listing displaying houseplants with thumbnails, descriptions, and prices.
- Interactive shopping cart powered by Redux state management.
- Dynamic cart count badge in navbar updating across pages.
- Add, update quantity, and delete functionality in the cart page.

## Technologies Used
- React
- Redux Toolkit
- CSS3
